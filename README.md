# Student Score Analyzer

A Python-based console application designed to collect student scores, validate user input, calculate performance statistics, and generate a student report.

## Features

- Validate the number of students.
- Validate student names and prevent duplicate entries.
- Validate scores within the range of 0 to 100.
- Calculate the average student score.
- Identify students with the highest and lowest scores, including ties.
- Rank students based on their scores.
- Assign performance grades:
  - 90–100: Excellent
  - 80–89: Very Good
  - 70–79: Good
  - 50–69: Pass
  - Below 50: Fail
- Generate a formatted student performance report.

## Technologies Used

- Python 3
- Functions
- Dictionaries
- Lists and Tuples
- Loops and Conditional Statements
- Exception Handling
- Lambda Functions
- Sorting and Enumerate
- Docstrings

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:

   ```bash
   git clone https://github.com/Emadnashaat/student-score-analyzer.git
   ```

3. Navigate to the project folder:

   ```bash
   cd student-score-analyzer
   ```

4. Run the application:

   ```bash
   python "Student Score Analyzer.py"
   ```
